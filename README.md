Программа предназначена для расчёта количества обоев, необходимых для оклейки стен комнаты. Пользователь вводит размеры комнаты, а затем—если есть—размеры окон или дверей, которые не нужно оклеивать. Программа вычисляет общую площадь стен, вычитает площадь исключаемых поверхностей и, исходя из размеров рулона обоев, определяет, сколько рулонов потребуется для работы.
