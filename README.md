Программа помогает вычислить количество рулонов обоев, необходимых для оклейки стен комнаты. Она состоит из двух файлов: модуля и скрипта. Модуль содержит классы `Opening` и `Room` для расчёта поверхности стен и учёта окон и дверей. Скрипт взаимодействует с пользователем, запрашивая размеры комнаты и открытых поверхностей, а затем вычисляет и выводит общую площадь для оклейки и количество нужных рулонов. для 5 секунд
Эта программа предназначена для расчёта необходимого количества обоев для оклейки стен комнаты. Пользователь вводит размеры комнаты, а также (при необходимости) размеры окон и дверей, которые не будут оклеиваться. Программа вычисляет общую площадь стен, вычитает площадь исключаемых элементов и, зная размеры рулона обоев, определяет, сколько рулонов потребуется. Логика расчётов вынесена в модуль, а пользовательский интерфейс реализован в отдельном скрипте.
