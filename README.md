Программа моделирует разделение персонажей на две армии. Класс Person создаёт объекты с уникальным id и случайно назначенной командой (1 или 2). От него наследуются Hero и Soldier. Создаются два героя, а затем генерируется 20 солдат, которые распределяются по армиям в зависимости от их команды. В конце программа выводит размер каждой армии.
