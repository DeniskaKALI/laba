Программа имитирует бой двух воинов. У каждого из них по 100 единиц здоровья. В цикле случайным образом выбирается атакующий, который наносит удар, уменьшая здоровье противника на 20 единиц. После каждого удара выводится, кто атаковал и сколько здоровья осталось у соперника. Бой продолжается, пока здоровье одного из бойцов не станет ≤ 0. В конце программа объявляет победителя.
