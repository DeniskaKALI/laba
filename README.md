Программа создаёт три объекта класса Person, каждый из которых имеет имя, фамилию и уровень навыка. Метод info() выводит информацию о каждом человеке. При удалении объекта (del) срабатывает деструктор __del__, который выводит сообщение о прощании. В конце удаляется объект helper, и программа завершает работу.
